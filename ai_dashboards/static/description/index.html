Ask for a dashboard. Get a real one.

You already pay for Claude or ChatGPT. Connect it once, describe the dashboard you want in plain English, and it lands in Odoo as an app you and your team open like any other screen.

The AI never writes code

It writes a specification — which model, which filter, which grouping, which measures — and Odoo validates it and draws the charts. There is no generated SQL anywhere in this module, and that matters more than it sounds: SQL written by a language model runs outside the ORM, and therefore outside every access right and record rule your database has. A specification cannot, because it is data rather than instructions.

Dashboards store the question, not the answer

A saved dashboard holds "revenue by month, this year" — never the numbers. The query runs when somebody opens it, as that person, through the ORM. So a dashboard shared with a colleague shows their permitted slice, is never stale, and respects multi-company boundaries without anyone configuring it.

Built for more than one person

This is where a dashboard stops being your own workspace and becomes something a team runs on.

Email it to yourself, every weekday Weekday, weekly or monthly — and each email is calculated with that recipient's permissions at the moment it is sent. So one shared dashboard mails each person their own figures, rather than a copy of somebody else's.
Share with people or whole teams Sharing grants sight, never edit — one person's change cannot silently rewrite what a team looks at each morning. And because the dashboard stores the question, each viewer still sees only the records their own Odoo permissions allow.
Compare against last year Or the previous period, across the whole dashboard at once, switchable by whoever is reading it.
Pivot tables that survive real data Two dimensions, with both axes paged independently — so customers-by-month works on an actual customer list rather than only a demo one.
It explains itself A plain-English account, per dashboard, of exactly which data it reads and whose permissions it runs under — the page you show whoever has to approve it.
