3CX Phone System Integration

Know who is calling, keep every call in Odoo, and never lose a missed call.

  • Caller ID — when a call rings, 3CX shows the Odoo contact, company or lead, with a link to the record.
  • Search Odoo from 3CX — agents find contacts and leads by name, company, number or email in the 3CX Web Client and call them.
  • Call log — every call lands in the chatter and under CRM › Reporting › 3CX Calls: by agent, day, type, duration, with the recording link and the 3CX AI summary when available.
  • Missed-call follow-up — a missed call schedules a Call back activity; the next answered call closes it.
  • Chats too — SMS, WhatsApp and live-chat conversations are logged.
  • Leads from the phone — created from the 3CX client, or automatically for unknown callers.
  • Agents — each user's 3CX extension on their user form; calls are logged in their name.

Setup

  1. Install the module. Settings › 3CX shows the API key and a Download 3cx_odoo.xml link.
  2. In the 3CX Admin Console, Integrations › CRM › Add, upload the file and enter the key.
  3. Restart the 3CX System service and press Test with a number that exists in Odoo.

Requires 3CX PRO or Enterprise (server-side CRM integration), V18 or V20. Goes beyond 3CX's built-in Odoo template: leads and opportunities, activities, call reporting, agent mapping, one dedicated key instead of a user API key.
