What you can control

Menus & Models

  • Hide any menu / sub-menu (whole sub-tree)
  • Hide the Apps installer menu
  • Hide Create, Edit, Delete, Duplicate
  • Hide Archive, Import, Export
  • Make a whole model read-only

Fields

  • Make any field Invisible, Read-only or Required
  • Invisible also drops it from list, filters, group-by & export
  • Remove inline Create / Create & Edit
  • Remove the internal / external link button
  • Conditional field attributes

Buttons, Tabs & Search

  • Hide header / statusbar buttons
  • Hide notebook tabs & kanban links
  • Hide search filters & group-by options
  • Hide the search panel
  • Conditional button / tab visibility

Records & Chatter

  • Conditional record access (read / create / edit / delete)
  • Soft (hide-only) or hard restrictions by domain
  • Hide the whole chatter
  • Hide Send message / Log note / Activities / Followers
  • Reports & contextual actions

User & Global

  • Read-only user (enforced server-side)
  • Disable developer mode
  • Disable login
  • Hide Import / Export globally
  • Hide “Add a Property”

Built right

  • One profile → many users, groups, companies
  • Cached engine — no per-request searches
  • Anti-lockout for administrators
  • Server-side enforcement where it matters
  • Clean, upgrade-safe extension points
Security note: Hiding an element in the UI is a usability layer. Access Manager Pro additionally enforces read-only users, record domains, archive, export and login on the server. For hardened data isolation, pair record (domain) rules with native record rules.
