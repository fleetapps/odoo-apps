Security you can defend in a review

OAuth 2.1 + PKCE (S256)

Self-contained Authorization Server: RFC 9728/8414 discovery, RFC 7591 dynamic registration, RFC 8707 audience-bound tokens, refresh rotation.

Secrets hashed at rest

Only SHA-256 digests are stored for keys, codes and tokens. Plaintext is shown exactly once.

Defence in depth

The MCP scope can only narrow native Odoo permissions, never widen them. Multi-company isolation is preserved.

FAQ

Which AI clients are supported?

Any MCP client speaking Streamable HTTP — Claude, ChatGPT, Gemini, Cursor, Copilot, VS Code and more.

Do I need an extra server or proxy?

No. The MCP server runs inside Odoo with zero external Python dependencies.

Can the AI get admin rights?

Never. It operates as the connected user, bounded further by the governance scope.

Can it change data?

Only if the scope allows writes — and you can require human approval for every one.
