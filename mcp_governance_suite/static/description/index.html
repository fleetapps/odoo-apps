What it does

Scopes

  • Per-model read / create / write / delete
  • Field blacklist — never returned, never accepted
  • Record domain ANDed onto every read
  • Read-only kill-switch per scope
  • Calls-per-hour ceiling per scope

API keys

  • Bound to one Odoo user and one scope
  • Calls run as that user — ACLs and record rules still apply
  • Secret shown once; only its SHA-256 is stored
  • Expiry dates, with an expiring-soon view

Approvals

  • Writes pause as a request instead of executing
  • Approver sees the model, the record and the payload
  • Approve executes under the key's user, not yours
  • Chatter keeps the decision trail

Audit & cost

  • One row per tool call: key, tool, outcome, duration
  • Size-based token estimate for cost tracking
  • Graph and pivot views over the whole history
  • Retention window with a weekly purge

The dashboard

The app opens on a single screen that answers the three questions an administrator actually has: is the endpoint live, who is calling it, and what is waiting on me. Endpoint status and protocol revision, activity for the last fourteen days split into successes and errors, the busiest tools and keys, pending approvals you can decide in place, your scopes and keys at a glance, and the latest calls. A fresh install shows a three-step setup checklist in the order that works — scope, key, then switch the server on.

How it fits together

1. Define a scope — the models and operations an agent may reach.
2. Issue an API key bound to that scope and to an Odoo user.
3. Switch the server on. Until then /mcp/v1 answers 503 to every caller.
4. Point your MCP client at https://your-odoo/mcp/v1 with the key as a Bearer token.

Defense in depth

A scope narrows; it never widens. Because every call executes as the key's Odoo user, ir.model.access and record rules apply underneath the scope — so a misconfigured scope cannot hand an agent more than the user behind it already had. The master switch is off on install, so the endpoint is never live the moment the module lands.
