1. Go to *Invoicing → Configuration → Currency Rate Providers*.
2. Create a provider and set *Provider* to **Central Bank of Kenya**.
3. Choose the *CBK Series*:
   - **End of month** (default) — the rate on the last published day of the
     month. The usual basis for revaluing balances.
   - **Monthly average** — the month's average, stamped on the first of the
     month so it applies across the period it describes.
4. Select the currencies to maintain and set the update interval.
5. Enable *Automatic Currency Rates* on the company.
